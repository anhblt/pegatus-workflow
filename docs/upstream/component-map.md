## Stack and dependency rules

The .NET audit inventory includes the **five permitted plugin groups only**: `dotnet`, `dotnet-advanced`, `dotnet-data`, `dotnet-test`, and `dotnet-aspnetcore`. Each selected skill is a folder, not just `SKILL.md`; for example `dotnet/msbuild` has a references tree, `dotnet-test/coverage-analysis` has PowerShell scripts, and `dotnet-test/code-testing-extensions` links language extensions. `dotnet/plugin.json` declares `lspServers`, which is a separate host integration and is not supplied by copying its skill folder. `dotnet-test/run-tests` has optional repository overlays and supports xUnit, while `writing-mstest-tests` is explicitly MSTest-specific. The packaging allowlist must exclude unrelated language extensions/MSTest guidance from default activation and reject unresolved cross-plugin references. Respect the target's actual SDK/framework, EF Core and SQL Server versions, and test framework; do not infer migrations from examples.

The Vercel audit includes both complete skill folders (90 files), their rule pages, `AGENTS.md`, metadata and README. `react-best-practices` mixes React and Next.js advice; gate Next.js-only rules on an actual Next.js project. `composition-patterns` includes a React 19 rule. Preserve local links and attribution when extracting a subset.

ECC `continuous-learning-v2` includes shell, Python, observer Markdown and config files; a portable Pegatus learning implementation must not silently treat its `SKILL.md` alone as complete. ECC's Antigravity target references `./helpers` in `scripts/lib/install-targets/`; that dependency is represented by the lock closure. ECC's orchestration script imports the tmux orchestrator. No selected JavaScript relative import remained unresolved in the audited closure generator. External binaries, environment variables, nonliteral runtime imports, and prose links still require packaging and host tests.

## AgentShield package and scanner contract

Selected package: `ecc-agentshield@1.6.0`, npm integrity `sha512-lpeHG96DtEn7ofq7Iiyvq29piQOwParaiZOdDB206i4ZeCL4yjwT6xN5BSGI4yhCEAN0eO0f9F9hxHLBuRqf/g==`, matched to source tag `v1.6.0` / commit `b0891303bdcd6037376a94263d45cfd2ff3dfb98`. The published package declares Node `>=20`, MIT, `agentshield` bin, and seven direct runtime dependencies (`@anthropic-ai/sdk`, `chalk`, `commander`, `glob`, `smol-toml`, `yaml`, `zod`) with semver ranges. The lock records all 61 resolved npm package versions and integrity strings from the isolated audit installation. A tarball alone cannot run: isolated `node dist/index.js --help` failed with missing `smol-toml`; installing the package and its dependencies in audit scratch with `--ignore-scripts` made CLI help work. Shipped installation must materialize this exact graph, verify tarball integrity and prove Linux resolution; never use unpinned `npx` or a global install.

Default local invocation contract: `agentshield scan --path <explicit-existing-root> --format json`, without `--fix`, `--deep`, `--opus`, `--injection`, `--sandbox`, `--supply-chain-online`, watch or runtime modes. JSON top-level keys observed: `timestamp`, `targetPath`, `findings`, `score`, `summary`, `defenses`, `harnessAdapters`. Findings include `id`, `severity`, `category`, `title`, `description`, `file`, optional `line`, and `evidence`; `summary` includes severity counts and `filesScanned`. Normalize location, severity, evidence and remediation (when provided), and add Pegatus suppression provenance. Empty-root success is **not** proof of coverage: observed `filesScanned=0`, `findings=0`, exit 0. Require expected relevant files to be discovered and report a coverage gap otherwise.

Observed isolated Windows fixture: benign empty directory exited **0**; a `CLAUDE.md` containing a prompt override exited **2** with 14 findings including three critical; nonexistent path exited **1** with stderr and no JSON. Source shows exit 2 when `summary.critical > 0`, plus other option-specific exits. The wrapper must classify parse errors, missing output, nonzero execution failure and incomplete coverage as blocked/failed scanning; critical findings block the affected gate until user disposition. Do not equate arbitrary nonzero exits with the same severity or treat a zero exit as a clean report without parsing JSON.

Default static scan is local source analysis. Online supply-chain lookup is opt-in via `--supply-chain-online`; `--opus`/`--injection` use a provider API key and can transmit inputs; `--sandbox` executes hooks. These modes are outside the default contract. AgentShield describes Claude config scanning and newer local adapter evidence for other harnesses, but it does not prove full Codex/Antigravity config coverage, changed-code security, or Linux behavior. Practical fixtures on Windows and Linux and host-specific coverage inspection remain acceptance gates.
