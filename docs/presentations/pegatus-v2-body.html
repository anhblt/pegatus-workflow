Adaptive routing

Plan → Implement → Review → Verify → Report

Explicit design and scope approval before implementation. Material scope changes reopen affected approvals.

Observe → Gather evidence → Diagnose → Route a fix

The AI host coordinates these procedures; Pegatus does not run an autonomous background service.
