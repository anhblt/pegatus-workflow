# Host capability contract (source review, 2026-10-12)

## Browser-testing extension (October 2026)

The catalog now adds browser-tester and pegatus-browser-test. Existing adapters generate the role and skill/command wrappers at their normal paths; Antigravity retains portable role guidance and workflow invocation. Playwright MCP must be configured separately in each host execution environment. No native browser session or delegated MCP tool inheritance has been qualified by this extension. Verify actual worker access; missing tools block selected scenarios. Inline execution discloses the lack of independent delegation. See [browser setup and evidence](../browser-testing.md). The dated source review and historical observations below remain unchanged.

Status labels: **documented** means a current official host page describes the capability; **live acceptance required** means the adapter must be tried in the target host/version and OS; **unsupported/unverified** means no official guarantee was found. A documented hook event is not proof that every tool path is enforceable. ECC and Pegatus V1 generated files are reference examples, not host evidence.

Codex hook qualification is material: official docs say specialized tool paths can opt out of the default hook path; a callback error, timeout or malformed response can fail without blocking the tool. Cloud orchestration does not support local command/prompt/agent handlers or `SessionEnd` MCP hooks even when tools execute locally. Pegatus must report these as guardrails and keep required gates inside its own CLI operation. [OpenAI Docs: hooks](https://learn.chatgpt.com/docs/hooks). Plugin-bundled hooks require explicit trust; enabling a plugin alone does not authorize them. [OpenAI Docs: plugin packaging](https://developers.openai.com/plugins/build/plugins).

Claude Code may read `AGENTS.md` directly only in supported versions/configurations, and when a `CLAUDE.md` exists its default behavior can prefer the latter. Do not silently assume a shared `AGENTS.md` is loaded. The adapter must inspect existing instructions and choose an explicit import/compatible path without overwriting user files. [Claude memory](https://code.claude.com/docs/en/memory).

**Live acceptance queue (Task 10):** capture exact host/client versions, Windows and Linux behavior, skill discovery and direct invocation, role delegation, command aliases, instruction precedence, hook event payloads/denials/failures, compaction/resume checkpointing, and user/project install conflicts. Antigravity native hooks/custom agents and skill manifest semantics remain unverified; doctor should label those explicit-call or instruction-only until observed. No global host installation or live host trial was performed in this source audit.
