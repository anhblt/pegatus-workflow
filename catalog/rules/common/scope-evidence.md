Keep work within approved scope. Conversational brainstorming creates no files or checkpoints by default; save notes only when requested, without starting tracked work. Small understood fixes omit unnecessary artifacts; feature implementation requires design/scope approval. Preserve approvals on resume; seek approval for material changes and unauthorized consequential actions. For tracked project work, record final-state verification evidence and checkpoint before handoff/interruption.
