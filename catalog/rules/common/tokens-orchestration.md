Retrieve through focused instructed indexes; load task-specific resources progressively. Roles use configured host model tiers without hardcoded models. Default two independent workers, distinct ownership, agreed dependencies; label inline review limitations. Keep stable instructions separate from dynamic context; report unavailable measurements.

Use src/telemetry/usage.mjs buildContextManifest and project tokenControls for bounded reference packets. Block dependent work if required context exceeds the limits; preserve instruction and check requirements. resolveRoleTier preserves fast, standard and deep role assignments and explicit project-over-user model/effort mappings. For an unconfigured tier, the trusted coordinator selects from the current host spawn allowlist: fast uses a cheap, fast model for mechanical work; standard a balanced model for integration and debugging; deep the strongest suitable model for architecture and complex reasoning. Specify both model and effort using actual host capabilities and record the pair, tier and reason before spawning. Follow the actual tool's fork restrictions. Workers cannot select replacements or change tiers. Unsupported explicit mappings retain host defaults with warnings; absent capability evidence or selection support also requires disclosed host-default fallback. limitOutput requires visible truncation markers and retained full-output references. recordUsage preserves unavailable measurements as null. These helpers and generated role guidance do not prove native host enforcement.
