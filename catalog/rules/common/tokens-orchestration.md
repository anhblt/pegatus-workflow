Retrieve through focused instructed indexes; load task-specific resources progressively. Roles use configured host model tiers without hardcoded models. Default two independent workers, distinct ownership, agreed dependencies; label inline review limitations. Keep stable instructions separate from dynamic context; report unavailable measurements.

Use src/telemetry/usage.mjs buildContextManifest and project tokenControls for bounded reference packets. Block dependent work if required context exceeds the limits; preserve instruction and check requirements. resolveRoleTier uses the team's fixed model/effort mapping and explicit capability declaration; unknown support retains host defaults with a warning, never an agent-selected replacement. limitOutput requires visible truncation markers and retained full-output references. recordUsage preserves unavailable measurements as null. These helpers and generated role guidance do not prove native host enforcement.
