# Audited adaptation decisions

ECC sources are audited originals, pinned and hashed in sources.lock.json. Manifest source paths identify what was read; entry adaptation notes describe the retained behavior. Host-specific model/tool labels and unsolicited proactive agent activation are removed.

- code-explorer and iterative-retrieval: retain entry-point/path/dependency tracing and evaluate/refine retrieval. Instructed indexes/flows precede any broad fallback; trusted context resolution supplies readInstructions and provenance.
- planner/architect: retain current-state/reuse analysis, component/API contracts, alternatives, dependency-ordered file steps, risks and success criteria. Feature gates are design/scope approvals, small fixes omit unnecessary spec artifacts.
- code-reviewer: retain exact location, concrete trigger/consequence, surrounding caller context, defensible severity, high/critical guard proof, consolidated findings and valid zero-findings outcomes. Pegatus code-reviewer covers generic TypeScript as well as React/.NET lanes; no missing ECC typescript-reviewer dependency is implied.
- csharp/react reviewers: retain applicable async/disposal/data/hook/state/accessibility/security questions. Convert implementation guidance to owned backend/frontend roles; actual framework/version controls Next.js/.NET-specific advice. No unconditional lint/plugin or framework upgrades.
- build-error-resolver/verification-loop: retain categorize, minimal repair, build/type/lint/test/security/diff sequence. Replace Bash pipelines and fixed 80-percent coverage with configured commands, prerequisites, exact outcomes, final-state evidence and repairLimit three. Missing Docker integration tests are NOT RUN.
- security-reviewer/security-scan: retain auth/injection/secret/trust-boundary review; configuration scan is separate. Replace global install/unpinned npx/online modes with planned pinned local wrapper and explicit scope/JSON/coverage checks; no scanner completeness claim.
- parallel-execution-optimizer: retain objective/done signal, lane dependency graph, isolated ownership, gated integration and verification. Replace tmux/shell assumptions with host capability and explicit inline limitation; default two workers.
- strategic-compact/session commands: retain milestone/handoff recovery. Replace ECC host-home/session files with atomic project .pegatus state, branch/fingerprint reconciliation and coordinator ownership.
- continuous-learning-v2: retain atomic evidence-backed project observations and deduplication. Replace confidence-led/global automatic promotion and shell/Python observer runtime with reviewed candidates and authoritative knowledge owner; no unattended policy changes.
- prompt-caching/token-card/performance: retain focused progressive loading and stable approved instructions separate from dynamic context. Model tier choices belong to fixed per-host config; unavailable measurements remain unavailable. No claimed measured savings.

Stack packaging retains upstream bytes and local scripts/references/agents without copying additional plugin groups. Vercel rule bridges are materialized files, not linter exceptions. Cross-pack skill dependencies resolve by stable catalog ID. Optional repository overlays remain project-owned, not missing vendor resources. Read actual SDK/test platform before running bundled scripts; never blindly execute upstream instructions.
