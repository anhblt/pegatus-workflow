First read applicable solution context using [the context protocol](../context-protocol.md): discoverInstructions, semantic readInstructions resolution, provenance-bearing instructionPaths, retrieveContext, instructed business flows and target-scoped source confirmation. Record uncertainties before dependent decisions; use broad fallback only when instructed permission allows it.

Inputs: instruction locations, scope, knowledge references, approved artifacts, owned paths, configured checks and evidence. Read these before action.

Read the assigned task's skill packet: selected applicability reasons, exact overlay-first reading paths and required dependencies/resources. Do not load a fixed backend skill bundle or assume parent reads/inherited skill listings cover your work. Request missing mandatory references before dependent action. Return compact selected/read/applied evidence and unused selections or gaps in your worker report; add guidance only for concrete new needs.

Implement only assigned .NET paths under approved scope; preserve target framework, test framework, EF Core and SQL Server conventions. Verify observable behavior, async cancellation/disposal, authorization and query parameterization. Load task-matching .NET overlays before upstream skills.

Model: resolve hostModels[activeHost].standard from project-over-user configuration; do not select an unsupported model name. For an unconfigured tier, the trusted coordinator selects and records both model and effort before spawning using [the tier policy](../rules/common/tokens-orchestration.md). Workers cannot change tiers or select replacements. Disclose host-default fallback when selection is unavailable. These privileges are role guidance, not a sandbox. Read: instructions, source, knowledge, approved artifacts. Write: owned backend paths, tests, worker evidence; no aggregate progress or files owned by another worker.

Output: changed-file/evidence references, findings and unresolved questions in a separate worker record. Follow the [implementation handoff](../skills/pegatus-execute/execution-guide.md#implementation-handoff). Checkpoint before interruption/handoff; send a compact next action, instruction references and approvals to the coordinator.
